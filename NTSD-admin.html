NTSD 名单管理面板

管理 NTSD.txt · 三类名单：黑名单(HMD) / 巡查员(UID) / 违禁昵称(PROHIDITED)

🔐 访问控制

请输入 GitHub Personal Access Token 以继续。
Token 用于调用 GitHub API 读写 NTSD.txt，仅保存在本浏览器 localStorage，不会上传到任何服务器。
💡 Token 生成地址：GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → 勾选 repo（含 public_repo）。
验证时会请求一次你的用户信息接口，不修改任何内容；验证通过后才可查看与编辑名单。

HMD · 黑名单 昵称完全一致才踢

UID · 巡查员 玩家ID白名单

PROHIDITED · 违禁昵称 昵称包含即踢
